# 🎬 Netflix Data Analysis Using SQL

## 📌 Project Overview
This project analyzes the **Netflix dataset** using SQL to uncover insights about content trends, global reach, and audience preferences.  
It highlights how movies and shows vary across countries, genres, directors, ratings, and duration, providing a clear picture of Netflix’s content strategy.

---

## 🎯 Objectives
- Analyze **content trends** by year, type, and duration.  
- Examine **geographic distribution** of shows and movies.  
- Identify **top genres, directors, and cast members**.  
- Assess **content rating patterns** to understand audience demographics.  
- Discover **recent additions**, **high-duration titles**, and **regional preferences**.  

---

## 🛠️ Tech Stack
- **Database:** MySQL / SQL  
- **Dataset:** Netflix titles dataset (movies & TV shows)  
- **Visualization/Insights:** SQL queries + PowerPoint summary  

---

## 📂 Project Files
- `Netflixx.sql` → Contains all SQL queries used for analysis.  
- `NETFLIX DATA ANALYSIS USING SQL.pptx` → Presentation of queries, results, and insights.  

---

## 📊 Key SQL Queries
- **Top 10 Longest Movies**  
- **Top 10 Countries by Number of Movies**  
- **Total Movies and Shows**  
- **Most Common Movie Ratings**  
- **Top 5 Genres for Movies**  
- **Movies with “Love” in the Title**  
- **Average Duration of Movies**  
- **Top Directors by Movie Count**  
- **Recently Added Movies**  
- **Movies with Unknown Cast/Directors**  

👉 Check [`Netflixx.sql`](./Netflixx.sql) for full list of queries.

---

## 🔎 Insights Gained
- Content additions have **increased steadily** over the years, showing platform growth.  
- **United States** and **India** lead in content production.  
- TV Shows and Movies vary significantly in **duration**, reflecting content diversity.  
- **Genres and directors** highlight audience preferences and industry trends.  
- Recent years saw a **spike in new content**, especially binge-worthy titles.  
- Keywords like **"Love"** appear frequently, indicating popular content themes.  

---

## ✅ Conclusion
- Identified **most active years & countries** for content production.  
- Analyzed **content trends by genre, duration, and ratings**.  
- Detected **missing metadata** (unknown cast/directors).  
- Extracted **recently added titles** and **popular regional genres**.  
- Provided insights into **user-oriented patterns** (e.g., keywords in titles).
